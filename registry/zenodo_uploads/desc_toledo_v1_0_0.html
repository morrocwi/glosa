What this is. Toledo — named after the Toledo School of Translators, where one text was read across languages — is the programme's single permanent home for equations and their machine checks: a public git repository (https://github.com/morrocwi/toledo) whose tagged releases are deposited under this concept DOI. Scope is equations and Th_coqc only: registries, persistent codes, an append-only lineage log per code, and Coq 8.20 sources whose file name is the code.

Code scheme. Root codes reuse the identifiers of Readout Genesis verbatim (Appendix C EQ-nnn, the one-line weld, named items such as MQ.08, A.5, A.8). Every other equation is a reading of a root: <root>/<D>.<nn>.v<k> with D ∈ {E epistemic, H human–AI, S social, W world-system, M method, P physics, C chemistry, B biology/health}. Parents are listed by code back to the root; a bundle that was found to hold several distinct formulas is retired with status split and its members carry their own codes; a row whose source is prose carries status not_an_equation with a pointer and no code. Two raw equations share one code only under the equivalence criterion (renaming, positive scale, constant substitution); otherwise they are related, never merged.

Coq: 339 native files named by code, built one file at a time, 162 lemmas closed under the global context; imported developments mirrored with provenance and re-verified here: 3,289 identifiers, 3,125 closed, 164 carrying named axioms, 0 build failures. Generated views: JSON-LD entries, TOLEDO.json, GraphML/Turtle graph, an Obsidian-style vault, a static site (1,383 pages) and this catalogue PDF (126 pp).

Status and limits. K0 working release. Th_coqc certifies the internal consistency of stated finite models, never empirical truth. Not yet done, stated in the README: 210 entries have mapped Coq identifiers but no Toledo-named wrapper file; 246 have no formalisation; roots for RD1–RD9, the Theta programme and CMC are absent from the root registry, so no code was invented for them; 332 tiers remain untagged because the sources give none.
