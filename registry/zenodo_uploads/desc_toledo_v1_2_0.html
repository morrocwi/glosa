What this is. Toledo is the programme's single permanent home for equations and their machine checks: a public git repository (https://github.com/morrocwi/toledo) whose tagged releases are deposited under this concept DOI. Scope is equations and Th_coqc only: registries, persistent codes (<root>/<D>.<nn>.v<k>, D ∈ {E, H, S, W, M, P, C, B}), parents by code back to a root, an append-only lineage log, and Coq 8.20 sources whose file name is the code. Founder rule (2026-09-07): every equation of the programme is looked up here first and registered here before it is written or cited elsewhere; no AI agent in the programme may use an unregistered equation.
