What this is. Toledo is the programme's single permanent home for equations and their machine checks: a public git repository (https://github.com/morrocwi/toledo) whose tagged releases are deposited under this concept DOI. Scope is equations and Th_coqc only: registries, persistent codes (<root>/<D>.<nn>.v<k>), parents by code back to a root, an append-only lineage log, Coq 8.20 sources whose file name is the code, an MCP server and CLI for lookup, and a static read API. Founder rules (2026-09-07): every equation is looked up here first and registered here before it is written or cited elsewhere; no AI agent in the programme may use an unregistered equation.
