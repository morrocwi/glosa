# lineage/ — what glosa builds on, named and bounded

This directory answers one question for any reader, human or AI: **where did each piece of glosa
come from, and what exactly does glosa claim to preserve, re-derive, or supersede from it?**
Every "preserved" claim anywhere in this repo must point to a file path here, or to a section of
`design/FOUNDATION_v0.3.md` this file cross-references — never asserted loose in prose.

Comparison language throughout this directory, and every file it points to, is **same / different
/ cited** — never "novel," "first," "unprecedented," "prior art," "seminal," "pioneering," or "we
borrow/take from." See `design/FOUNDATION_v0.3.md` §1.1 (founder ruling, request 31) and
`lineage/RELATION_TO_STANDALONE_SCHOLAR.md` §3 for the supersession record this rule itself sits
on.

## Why this directory exists (one-fact-one-home, applied to lineage itself)

`design/FOUNDATION_v0.3.md` §1.2/§1.3 states the ancestor relationships and the anchor-preservation
obligation in prose, once. This directory is where that obligation becomes a checkable artifact
per ancestor — a reviewer, or a future AI session opening this repo cold, should never have to
re-derive "did glosa actually preserve invariant N" from FOUNDATION's prose alone; it should be a
row in one of the three ledger files above, with a file path or section number attached.

- **The Readout Condition's formal appendix and bibliography were never read** by any pass of this

  paper's core sections (`sources/READOUT_CONDITION_2026-08.txt`) only.
- **Every path in `design/REPO_SPEC_v0.3.md` beyond the bare repo shell is a specification, not a
  built file** as of this session (2026-09-04) — where a ledger file above cites a `methodology/`,
  `schema/`, `paper/`, or `scripts/` path, that path is *specified*, and this directory says so
  rather than implying it already exists and was checked.

  Per this repo's own gate (`AGENTS.md` rule 3, MC-01), the AI that authored them may not certify

  (`EPIS-KNOWLEDGE-VALIDATION`, inherited workspace-wide).
